# 🚢 Seaquest – Gra Zręcznościowa

Klasyczna gra zręcznościowa inspirowana retro tytułami, stworzona jako autorski projekt programistyczny. Celem projektu było praktyczne zastosowanie paradygmatów **programowania obiektowego (OOP)** oraz zarządzanie cyklem życia aplikacji.

![Screenshot z gry](.venv\Gra_Python\Images\Game_view.png)

## 💻 Wykorzystane technologie
* **Język programowania:** Python
* **Biblioteka / Silnik:** Pygame
* **Narzędzia:** Git, PyCharm

## ⚙️ Główne mechaniki i architektura kodu
* **Programowanie obiektowe:** Logika gry oparta na klasach (np. osobne klasy dla Gracza, Przeciwników, Pocisków).
* **Game Loop:** Zoptymalizowana pętla główna gry odpowiedzialna za renderowanie grafiki i aktualizację logiki w czasie rzeczywistym.
* **Detekcja kolizji:** System sprawdzający interakcje między obiektami na ekranie.
* **Zarządzanie stanem:** Przejścia między menu, rozgrywką a ekranem końcowym (Game Over).
